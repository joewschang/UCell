# 正式會員多球申購

## 會員怎麼操作

1. 會員在「正式會員申請」儲存個人資料後，於選購套組時選擇多球申購，輸入本次顆數。一次可選 2 至 63 顆。只買 1 顆可走原申請流程。
2. 每顆球各選資格套組、商品與適用的優惠碼。相同配置可複製，再改其中幾顆。各球可個別加購重銷，也可以略過。
3. 確認頁列出球位、推薦關係與逐球金額。「本次資格應付」合計各球資格套組及建立費，已扣除適用優惠。「生效後另付」列出各球選購的重銷金額。以送出當下系統核定的方案與報價為準。
4. 一次建立整組訂單。會員只需匯一次資格款，在多球申請頁回報金額、匯款時間及帳號末五碼。原頁可查詢回報和核款進度。
5. 若下單時尚未指定第 1 球的外部推薦球，可在收款確認前回到原申請核對球號與姓名後補填。只有第一顆需要指定外部推薦，其餘依預排自動帶入。
6. 財務核款、正式會員審核及安置完成後，在各球明細查看生效球號。會員可逐筆支付已生效球的重銷，每筆仍對應當初選擇的球及套組。

## 三球與四球的排列

| 本次球位 | 二元樹預排 | 推薦球 |
| --- | --- | --- |
| 第 1 球 | 由有權安置者確認組外位置 | 已核對的外部推薦球 |
| 第 2 球 | 第 1 球左側 | 第 1 球 |
| 第 3 球 | 第 1 球右側 | 第 1 球 |
| 第 4 球（如有） | 第 2 球左側 | 第 2 球 |

預覽使用本組序號，實際球號與生效狀態另行顯示。超過四顆時仍逐層由左至右填入。若選定的組外位置已被占用，系統會保留整組預排，待有權安置者改選可用位置。

## 財務與審核如何核對

- 從組內任一資格訂單開啟「整組資格收款」。比對會員回報、銀行入帳時間與整組應付金額後，輸入實收金額和收款憑證。
- 系統保留一張整組收款憑證，並依各資格訂單實際應付金額分攤。分攤、逐單付款事件及推薦關係在同一筆交易中完成。中途失敗可依原單重試。
- 會員回報後可以送審。正式核准前須確認實際收款，再由安置入口選定第 1 球的位置，系統一次安置整組。
- 重銷在資格收款時仍為待付款。各筆重銷沿用對應球的訂單編號，確認收款時會再次檢查生效狀態及時間。
- 未收款且已逾期的整組，如無匯款回報、配貨或其他作業紀錄，可重新選購。已有匯款紀錄的逾期訂單交由財務依原單核對，會員可保留訂單資訊供查詢。

本流程適用於自然人首次線上申請正式會員。

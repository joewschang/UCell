## 需釐清的來源差異（保留原文，不自行決定）

1. 手冊檔名為 1006，但封面仍為 REV20260831；版本索引記錄兩者。
2. 退貨截止同時出現「六個月（歷月）」及「180 日」；兩者在邊界日期可能不同。
3. 協議第三十條引用第二十四條，但該條談違約處分，疑為條次引用錯置。
4. 協議說不接受電子翻拍檔案，手冊說不接受翻拍不全的電子檔；需確認線上 KYC 的文件規格。
5. 重銷表固定 RPV／EPV 與手冊按每資格當月門檻計算的定義，須確認多筆、跨月及退貨時的使用口徑。
6. 首次套組是否另收／包含 600 元、繳費先後及預排球位，應與核准流程核對，不能僅由價格表推定豁免。
7. TIP-363 部分圖表標 TIP-636；商品名稱一律以正式訂購單及原始品號對照，不依圖表筆誤改 SKU。

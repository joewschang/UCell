# 後台訂單管理與建單

從後台「訂單管理」進入。清單、建單與明細一次顯示一項工作，手機與桌面使用同一套流程。

| 工作 | 操作 | 完成後可查 |
| --- | --- | --- |
| 找訂單 | 以訂單號、姓名或手機搜尋，搭配狀態篩選，每頁 8 筆。選取一筆進入明細。 | 返回清單會保留本次搜尋、狀態與頁碼。 |
| 建立訂單 | 按「新增訂單」，挑選有效球位，選用途、商品與數量，核對後送出。 | 開啟剛建立的待收款訂單。收款與出貨各自有獨立操作。 |
| 修改訂單 | 在明細的管理區查看可執行的操作，填寫理由。一般備註可直接更新，符合條件的未付款內容變更使用原系統的作廢重建流程。 | 由異動紀錄追查理由與結果。若其他承辦人已異動，需重新載入目前版本。 |
| 作廢與封存 | 符合作廢條件的未付款單可作廢。已付款單依明細可用的退換貨程序處理。已封存或作廢的訂單可用清單篩選找回。 | 保留原訂單及處理紀錄。 |
| 核對整組款項 | 卓越方案或自訂多球的組內訂單，從「收款」查看整組憑證與分攤明細。 | 每組只核對同一筆匯款，組內子單由整組申請管理。 |

系統管理員、訂單承辦與財務可進入建單並使用專用球位及商品選單。訂單維護由系統管理員及訂單承辦處理，稽核角色可查閱。各項後續作業依登入權限及訂單實際狀態顯示。

會員反映收不到通知時，可請對方在會員前台按「通知」。個人通知先載入，球號通知隨可用資格載入。

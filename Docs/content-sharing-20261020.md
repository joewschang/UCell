# 影音與推薦分享

## 使用者流程
- 公開影音可先看內容，再選擇登入、註冊、商品或活動；會員內容不公開外部影音網址。
- 分享會員由目前球位建立伺服器綁定內容及版本的連結。內容下架或取消分享即停止該分享入口。
- Google、LINE、帳密登入與註冊後回原影音。未取得球位的一般網路會員也可以閱讀會員影音。
- 複製、LINE、裝置分享、QR Code 都使用同一伺服器連結；取消裝置分享不顯示錯誤。

## 資料與指標
- 既有 ReferralLink、ReferralAttribution 與歷程保留，30 天政策及 Sponsor 不變。
- 新增 content_share_link 保存連結與建立時內容版本。畫面始終讀最新有效版本。
- 有效造訪為已接受推薦來源的去重瀏覽器紀錄；不是影片觀看完成數。
- 已連結會員包含原會員登入，不能稱作新註冊。新註冊需另以 Person 建立時間驗證。
- 訂單成效讀正式 retail referral 快照；球位訂單與內容轉換分開標示，不推算獎金。
- 不向分享者公開訪客姓名、電話、Email 或個別訂單。

## 發布與驗收
先增加資料表，再部署 API，最後會員、官網及管理介面。回滾應用可保留新增資料表。
檢查權限、跨球位、竄改內容、過期、取消分享、停用、重複操作、最新版本、三種登入返回、
無球位會員、空資料／錯誤／載入、手機排版與生產端點。正式帳號登入須使用獲授權測試帳號。

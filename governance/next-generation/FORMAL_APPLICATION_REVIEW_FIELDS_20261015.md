## 畫面配置
會員端上方為「我的正式會員申請」狀態卡，顯示草稿、已送出、審核中、需補件、已核准或未通過，附送出及更新時間、審核說明、重新整理按鈕。可編輯時下方顯示資料表，推薦球號在本人資料前；修改任何欄位後須重新儲存，才可送出該版本。

後台維持「會員管理 → 會員申請」入口，搜尋後開啟單筆申請。桌面左右分欄：左為個資、推薦與銀行資料，右為照片；窄螢幕上下排列。照片由使用者點擊後透過權限驗證 API 載入，不使用公開網址；關閉或離開即釋放瀏覽器暫存 URL。未通過安全檢查時不顯示圖片，也不偽造安全掃描結果。

## 推薦球號規則
沿用 SponsorResolver 的有效球號判定，須是有效且非本人持有的會員 Ball。儲存草稿可暫缺球號，但有填寫則驗證；正式送出時必填並重新驗證。推薦球號加密保存於既有版本化申請快照，不新增未經確認的組織安置。會員身分核准本身不建立或更換 Sponsor／Binary 關係。已有送出或核准的舊申請不自動改寫推薦資料。

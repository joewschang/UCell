UCell 官網 UX/UI 審查與改善 — 2026-10-20

審查範圍：官網首頁、產品、會員入口，以及全部 33 個 HTML 頁面的共用導覽與本機連結。實際瀏覽正式首頁；以桌面、390px 手機與 820px 平板預覽驗證新版主要操作。未宣稱完成所有內容頁的逐頁視覺審查。

已實作方案：
1. 首頁層級：將產品與近期活動提前，增加產品／活動／會員快速入口，主視覺直接引導產品；移除重複品牌大圖、重複入口與科學宣傳區塊，保留科學說明、品牌領導、圖片情境聲明與會員服務。
2. 導覽：標記所在頁面／分類；1180px 以下改用可捲動選單，避免導覽擠壓。支援 Escape、外部點擊、離開導覽焦點、選取連結及桌面尺寸重設收合。
3. 產品探索：名稱／SKU 即時搜尋、結果數、無結果說明、一鍵清除；以現有公開商品資料為唯一來源。商品說明移至列表下方，搜尋更容易到達。
4. 視覺與可及性：統一焦點樣式、跳至主要內容、手機留白與首屏高度、至少 44px 常用操作區、減少動態偏好支援；頁尾社群保持橫排。
5. 內容一致性：加入會員頁明示站內帳號、Google、LINE 三種途徑；更新現行手機／Email 非強制驗證說明。

驗證：11 項 Node DOM 測試通過，包括全部頁面的 skip target 與內部頁面連結、手機導覽行為、搜尋復原、商品來源與圖像 fallback、錯誤／空資料／無效價格處理。
瀏覽器：桌面搜尋名稱／編號、無結果與清除；手機選單與 Escape；手機內容寬度與 scrollWidth 均 375px（390px iframe 含捲軸）；平板雙欄產品。

後續建議（本次未實作）：以真實訪客回饋決定是否將九項主導覽整併；取得核准實拍圖後逐步替換情境圖；若要衡量註冊轉換，再另行規劃符合隱私設定的分析事件。本次未加追蹤工具。

部署僅覆寫官網 HTML、integration.css、main.js、integration.js；繼承現有映像的圖片、nginx 與 API 代理設定。會員／API／後台服務不需重新部署。

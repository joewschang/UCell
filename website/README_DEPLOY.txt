UCell Website V5.0 — Biotech Photo Edition
==============================================

定位：照片為主 × 生技研發 × 國際健康品牌。

內容
- 30 個 HTML 頁面（首頁、品牌、科學中心、六產品頁、健康、會員、法遵與政策頁）
- 所有網站引用圖片均打包在 assets/ 中，不依賴外部圖床
- 首頁生技研發大圖、設施／研究／產品／顯微鏡情境照片
- UCell Logo、品牌情境素材、產品視覺 SVG
- Responsive CSS、手機版導覽、JS 篩選／搜尋
- SEO canonical / Open Graph / Schema.org / sitemap.xml / robots.txt / 404

部署到 GoDaddy cPanel
1. 備份 public_html。
2. 將整個 ZIP 上傳到 public_html。
3. Extract 到 public_html 根目錄，確認 /public_html/index.html 直接存在。
4. 若覆蓋舊版，建議先將舊版完整備份。
5. Cloudflare 啟用後，以 https://ucell.life 測試首頁、內頁、產品頁與手機版。

重要影像聲明
- 生技廠、實驗室、研究人員、團隊與生活影像為品牌情境視覺／AI 輔助創作。
- 不代表 UCell 實際廠房、員工、設備或特定研究現場。
- 產品 SVG 亦為網站視覺示意，正式包裝、標示、規格以實際商品為準。

公開法遵
- 食品資訊不作醫療用途。
- 研究資料不等於終端食品可宣稱相同效果。
- 會員／合作內容不作固定收益、保證收入或投資承諾。

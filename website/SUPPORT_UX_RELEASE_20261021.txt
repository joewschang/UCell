UCell 官網第二階段：自助服務與瀏覽引導（2026-10-21）

已完成
1. FAQ：12 題原有內容分成 5 類，支援關鍵字、分類交集、全半形與英文大小寫正規化、結果數、無結果與清除復原。搜尋只在瀏覽器處理，不傳送或儲存搜尋文字。

內容維護
來源：website/content/faq.json（分類、固定 ID、問題、答案、關鍵字、相關連結）。
生成：在 website 目錄執行 npm run build:content。
驗證：npm test 會先檢查生成頁面與來源一致，再執行測試。不可直接修改生成區塊。
純文字內容經 HTML escaping；相關目的地限制現有官網 HTML。FAQ 預先生成到 HTML，未啟用 JavaScript 仍可閱讀。
這是版本控管的單一內容來源，尚不是管理後台 CMS；沒有新增後台編輯、審核、排程或發布 API。

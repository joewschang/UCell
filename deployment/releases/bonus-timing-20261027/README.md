# 獎金資格判斷與全球週結基礎

使用者核准：依 2026-10-26 對談建議執行。政策識別 `WEEK_CLOSE_PAYMENT_SNAPSHOT_20261027` 是版本代碼，實際生效時間由正式啟用交易記錄。

## 規則

- 新資格套組：確認收款交易內保存方案、推薦關係、領取者活躍與有效直推歷史快照；未安置前不提前認列 GPV。完成安置才產生 GPV，推薦與推薦對等讀付款快照，二元業績仍讀認列時的安置證據。
- 對碰：台北時間週一 00:00 為不含的結束時間，資格採前一毫秒，即週日結束。對碰對等沿用同一截止時間，使用對碰 K1 調整後的獎金基礎。
- 全球個人月認列量：以週日所屬月份選取完整週結，加總各球包含結轉、經週上限處理後的配對 GPV，不乘 K1。公司全球池使用同一組週結的來源 GPV，每筆來源只計一次。
- 歷史聘階保留；當期分配需符合該階當月認列量及月末活躍。比例、門檻及各階固定分配池不變。
- 週結未完成、週期重複、結轉鏈斷裂或來源證據不足時阻止全球月結，不發布部分結果。
- 全球退貨重算使用已封存的完整週結鏈，追溯結轉變動對後續月份的影響；舊全球快照仍走舊算法，不以新資料覆寫歷史證據。
- 普通訂單 EPV 與商品推薦原本依付款時間判斷，本次不改比例。EPV 維持逐月累計與新增超額認列。預付重銷保留首期付款、後續每月 1 日逐期認列。
- 核算與匯款分離，既有付款審核與退貨追回程序保留。

# 活動報到

會員在報名成功後直接取得私人 QR 碼，回到活動頁可重新取得（舊碼失效）。QR 內容不含會員個資；伺服器只儲存憑證雜湊。

後台每場已發布活動新增現場報到台，可使用相機、QR 圖片、文字憑證或會員編號。會員編號查詢先顯示姓名，確認後才補報名並報到。名冊的已報名列提供直接報到按鈕；確認出席仍是另一筆紀錄。

報到沿用既有活動開始至結束時間限制。補報名檢查會員資格、活動發布狀態、名額；取消後補報名建立新週期。活動鎖及冪等鍵防止重複紀錄。補報名與報到同一交易完成，保留兩個不可變參與事件。

驗證：後端 11 項檢查通過；前端既有測試中因入口及文字改動受影響的案例已更新並通過。瀏覽器驗證會員報名取得 QR、再次取得、跨活動拒絕、圖片解碼、重複掃碼、拒絕相機權限的替代操作、補報名及名冊報到，無頁面例外。實體相機硬體需由現場裝置允許相機後使用。

API 使用前一版正式映像為基底，只覆蓋 events service/controller。前端沿用正式映像配置，只覆蓋建置資產。無資料庫遷移。

`verify-rollback.cjs` 在正式資料庫交易內驗證報到與參與事件後整筆回滾，不保留測試報名或通知。執行方式：`node /app/release/event-checkin-20261023/verify-rollback.cjs`。

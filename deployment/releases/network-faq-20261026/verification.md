# 網路會員簡化註冊與常見問答管理

2026-10-26 已部署正式環境。

## 行為

- 初次網路會員註冊不蒐集真實姓名或證件號碼；顯示名稱、契約同意必填，手機／Email 至少一項，生日與性別選填。必填標示紅色星號。正式會員申請的身分資料要求維持。
- 未填的聯絡方式存為 null，不執行空值重複查詢；已填資料檢核格式並正規化。未驗證聯絡資料不標記為已驗證。未提供性別採不揭露。
- FAQ 從既有官網內容初始化 5 類、12 題。後台「系統治理 → 常見問答管理」提供新增、編輯、排序、分類、草稿／發布；未發布分類或問答不出現在公開查詢。
- FAQ 寫入使用版本檢查並記錄異動。管理角色為 SUPER_ADMIN、MEMBERSHIP_OPS、CUSTOMER_SERVICE。公開查詢不需要會員資格或登入。
- 官網使用同來源 `/api/public/faq` 代理，保留 CSP；會員前台直接讀取公開 API。兩者不使用舊靜態內容作為失敗回退。
- 同次後台發布包含先前身分證性別比對修正：有效臺灣身分證第二碼只比對已選男／女，尊重不揭露，不覆寫資料。

## 驗證

- 會員前端 16 項測試、後端 8 項測試、後台 25 項測試通過。
- 前後台 TypeScript 與正式建置通過，LINE、Google 與 Entra 設定檢查通過。
- Edge 畫面驗證：Email 單獨註冊、不填生日可前往確認；無真實姓名／證件欄位；手機畫面無水平溢出；公開 FAQ 與後台問答編輯儲存成功。
- 正式資料庫交易回滾驗證通過：Email-only Web 註冊、phone-only LINE 註冊、資格不自動建立、無證件資訊寫入、缺少聯絡方式拒絕、問答發布／隱藏、過期版本拒絕。驗收資料均未保留。
- 正式會員 FAQ 與官網 FAQ 均顯示 12 題；未登入管理 FAQ API 回傳 401；正式前端 bundle 已核對。
- migration：`20261026150000_faq_management`；既有已套用 migration 不重複匯入或覆寫後台修改。
